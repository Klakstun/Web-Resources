
# 📁 资源分享站 - 本地模拟版

> 一个纯前端静态资源分享网站，无需后端服务器即可本地运行。支持浏览资源、分类筛选、搜索、模拟上传分享等功能。

---

## 👋 欢迎使用

您好！这是一个**本地模拟的资源分享网站**，所有数据均为演示数据，存储在您的浏览器中。您可以把它当作一个真实的资源站来体验——浏览最新资源、按分类筛选、搜索感兴趣的内容，甚至可以“模拟上传”分享您喜欢的资源。

**所有操作都在您自己的电脑上完成，不会上传任何数据到互联网。**

---

## 🚀 如何运行（3步搞定）

### 方式一：直接打开（最简单）

1. 将本文件夹解压到电脑任意位置
2. 双击打开 `index.html` 文件
3. 开始浏览资源！

> ⚠️ 注意：由于浏览器安全策略，部分功能（如 `fetch` 加载 JSON）可能需要通过本地服务器运行。如果遇到资源加载失败，请参考下方“方式二”。

### 方式二：使用本地服务器（推荐）

如果您遇到跨域或资源加载问题，可以使用简单的本地服务器：

**使用 Python 3：**
```bash
# 在项目文件夹下打开终端，执行：
python -m http.server 8080
# 然后浏览器访问 http://localhost:8080
```

使用 VS Code Live Server：

· 安装 Live Server 插件
· 右键点击 index.html → Open with Live Server

🎮 功能介绍

首页 (index.html)

· 查看最新推荐的6个资源
· 快速浏览热门分类
· 一键跳转到资源大厅或分享页面

资源大厅 (resources.html)

· 搜索：按标题、描述、标签模糊搜索
· 分类筛选：按类别过滤资源
· 排序：默认 / 最新发布 / 热门下载
· 资源卡片：展示缩略图、分类、标题、描述、下载次数

分享资源 (upload.html)

· 填写表单模拟分享新资源
· 提交后资源会自动添加到“资源大厅”顶部
· 数据保存在浏览器本地（刷新页面不会丢失）

---

💾 数据持久化说明

· 初始资源数据来自 js/data.js（12个示例资源）
· 您通过 upload.html 提交的新资源会保存在浏览器的 localStorage 中
· 关闭浏览器重新打开后，您分享的资源依然存在
· 如需重置为初始数据，请打开浏览器开发者工具 → 应用 → 清除 localStorage

❓ 常见问题

Q: 为什么资源链接点开后是 example.com？
A: 这是模拟数据中的示例链接，仅供演示。您可以在 js/data.js 中修改为真实链接。

Q: 上传的资源刷新后还在吗？
A: 在的！资源会保存在您浏览器的本地存储中，除非手动清除。

Q: 如何删除我上传的资源？
A: 当前版本暂未提供删除功能。如需重置所有数据，请清除浏览器 localStorage 并刷新页面。

Q: 可以把这个网站部署到服务器上吗？
A: 可以！这是一个纯静态网站，您可以部署到任何静态托管服务（如 GitHub Pages、Vercel、Netlify 等）。

📝 自定义修改

修改初始资源数据

编辑 js/data.js 文件中的 window.allResources 数组，按格式添加或修改资源。

修改网站名称/Logo

编辑 index.html、resources.html、upload.html 中的 <title> 标签和 .logo h1 文字。

修改配色主题

编辑 css/style.css 中的全局颜色变量（主要颜色 #2563eb 可替换为您喜欢的颜色）。
